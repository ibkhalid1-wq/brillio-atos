## 2. What shipped today

The prototype now renders what the ontology actually says.

- **1:N → a list** of the child entity, headed the way its own list screen heads
  it. **N:M → chips.** **N:1 → a link** to the parent. Previously all three
  rendered identically and the fabric's `nav` nodes had no rendering at all
  (`.role` and `kind === "nav"` each appeared **zero** times in the assembler).
- **Unknown cardinality is no longer 1:N.** The generator writes `"unknown"` on
  every relation of a provisional draft deliberately; downstream it fell through
  to a child collection, so a prototype built before any interview asserted
  shapes nobody had confirmed. It is now the `undetermined` role — a list that
  says it is provisional — raised only on evidence (an FK the attributes carry,
  or a named standard prior), with the ground travelling alongside.
- **Drill-through.** The menu decides what is LISTED, not what can be opened.
  Reachable-only entities get a **detail screen only**. Measured: 41 screens /
  345,628 bytes, against 95 / 439,745 for a full closure and 13 / 247,110 before.
- **Four controls that lied now degrade to text**: "View all N", the browse
  fallback, agent-band entity chips, and the detail breadcrumb.
- **A `dead-end` check** in the render-QA gate, audited on the RENDERED document
  so it binds model-authored pages too. `#slug/id` needs a detail; `#slug` needs
  a list. `workbench` and `approvals` are reserved routes, not entities.
- **Three criticals** from the review: 166 dead link cards; the refine
  post-condition seeding without the vocabulary the page was assembled with; the
  stakeholder pilot assembling a different application from the operator's studio.

## 4. Traps this session actually hit — all of them cost real time

1. **Backtick inside a template literal** — in a CSS comment, in a run-agent
   prompt, and in a workflow script. **Three times.** One reached a FAILED
   DEPLOY, because `supabase/functions` is outside the typecheck. Before any
   deploy: `npx esbuild supabase/functions/run-agent/index.ts --outfile=/dev/null`
   and the same over `_shared/*.ts`. **This belongs in `validate` and is not there
   yet** — 20ms, catches the whole class.
2. **Literal control bytes make a file binary to grep.** `prototypeRefine.ts`
   carried two NULs; `grep` and `ripgrep` skipped the whole 600-line file in
   silence. Eight files were affected. Now guarded
   (`noLiteralControlBytes.test.ts`); `src/v3/lib/ledger/types.ts` is the one
   allow-listed exception (frozen core, literal `0x01`).
3. **Guards that assert nothing.** Two on this branch sat inside an `if` that was
   false on their fixture. One hid a real defect: `maxFanOut` defaults to 5 and
   the detail page slices at 5, so **"View all N" can never render** — still
   unfixed, recorded in `prototypeRelationRoles.test.ts`.
4. **Verify against rendered DOM, not source regex.** A regex matched words in
   prose and reported a feature present; another looked for `class="` in HTML
   that uses single quotes and reported it absent.
5. **Do not diagnose from a repo a workflow is mid-write in.** I attributed a

6. **G3 guard**: no client name in any `_shared` source, including comments.
